# Automation Scripts

This folder contains the scripts used to launch the various system components without directly manipulating the source code.

## Files
- `run_server.sh` : Startup script for the asynchronous web server and the analysis pipeline (developed by Masso).
- `run_fuzzer.py` : Execution script for the visual attack console and mutation generation (developed by Ephrem K.).

## Usage
Ensure the virtual environment is activated and dependencies are installed before running these scripts.
