# GuardOS LLM Documentation

This folder centralizes all technical and functional documentation for the project.

## Files
- `architecture.md` : Description of data flows, network routing, and technology choices (written by Ephrem K.).
- `api_specs.md` : Interface contracts, JSON input/output schemas, and HTTP endpoint definitions (written by Masso).

## Contribution Rules
Any major architectural change must be documented here and approved by the project manager before being integrated into the source code.
